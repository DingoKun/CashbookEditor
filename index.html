SW2.5 収支・持ち物エディタ

v1.4.7

ゆとシートJSONを読み込み、収支欄テキストと持ち物リストを生成します。

はじめての使い方
1．キャラクターJSONを読み込む

ゆとシートから出力したJSONファイルを、画面上部の「JSONファイル」で選択します。

2．価格と数量を確認する

必要に応じて価格CSVを読み込み、各行の価格・数量・加工内容を確認します。価格CSVがない項目は0Gになることがあります。

3．価格候補を整理する

JSONから収集された価格は「価格候補（整理中）」に入ります。名称や略称を整えた後、まとめて辞書へ登録できます。

4．出力をコピーする

「出力」を開き、収支履歴テキストまたは所持品テキストをコピーしてゆとシートへ貼り付けます。

武器・防具、装飾品、消耗品などの編集欄は最初から開いています。スマホでは表を左右にスクロールできます。数量は *3 の形式で出力されます。

読み込み時の注意
  • 収支履歴は、基本的に1行1項目で ::-価格 または ::-価格*数量 と書かれている行を読み取ります。
  • 数量は *5 形式を推奨します。×5 だけの場合、数量として扱えないことがあります。
  • 弾丸(12)・矢(12)・太矢(12) は、それぞれ12発／12本セットの商品として扱います。それ以外の商品の括弧内数字は数量化せず、個数は *数量 で指定してください。
  • 1行に複数の価格がある場合、最初の価格だけを読み取ることがあります。
  • 武器・防具の加工は、本体行の直後に ┗　::-価格 加工名 ランク メモ の形で書くと紐づきやすくなります。本体行から離れている加工行は紐づかない場合があります。
  • ツール未登録の加工は、加工名 Bランク メモ の順で書くと読み込みやすくなります。
  • // で始まるコメント行、表組み行、見出し行は読み込み対象外です。
  • 売却・返金・収入などの ::+ 行は、所持品購入としては読み込みません。セッション報酬はJSONの履歴欄から収入として読み込みます。
  • ゆとシートのルビ・太字・リンクなどは簡易変換しますが、完全再現ではありません。
