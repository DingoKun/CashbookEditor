# SW2.5 収支・持ち物エディタ

ゆとシートのソード・ワールド2.5用キャラクターデータを読み込み、買い物の収支や装備・所持品を整理する、ブラウザで使えるツールです。編集した内容を確認して、ゆとシートへ取り込むJSONを出力できます。

**[ツールを開く](https://dingokun.github.io/CashbookEditor/)**

## 使い方

公開ページを開き、キャラクターシートの閲覧URLからデータを読み込んでください。アイテムの追加・加工・買い足しを行い、変更内容を確認してJSONを出力します。

詳しい操作方法や注意事項は、画面右上の「使い方」にまとめています。CSVの登録、途中保存・再開、JSON出力の手順もそちらをご覧ください。

## 価格辞書と加工データ

ルールブック・サプリメントの商品一覧や価格表は付属していません。CSVを登録すると、辞書からアイテムを探して比較・追加したり、登録された加工データを利用したりできます。CSVなしの手入力でも利用できます。

CSVを自作する場合は、画面内の「辞書・加工データ管理」→「CSVを自作する」から、空のひな形と共通の作成ガイドをダウンロードしてください。別途サンプルCSVを取得する必要はありません。

## 保存について

- ゆとシートへは自動保存しません。出力したJSONをゆとシートへ取り込み、内容を確認して保存してください。
- 辞書・設定・途中保存は、利用中のブラウザに保存されます。端末やブラウザが異なる場合、自動では同期されません。
- 「途中保存」は編集中の作業用、「設定バックアップ」は辞書・設定などの移行用です。用途に合わせて使い分けてください。
