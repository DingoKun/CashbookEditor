# SW2.5 収支・持ち物エディタ

ゆとシートのソード・ワールド2.5用キャラクターデータを読み込み、買い物の収支や装備・所持品を整理する、ブラウザで使えるツールです。編集した内容を確認して、ゆとシートへ取り込むJSONを出力できます。

**[ツールを開く](https://dingokun.github.io/CashbookEditor/)**

## 使い方

公開ページを開き、キャラクターシートの閲覧URLからデータを読み込んでください。アイテムの追加・加工・買い足しを行い、変更内容を確認してJSONを出力します。

詳しい操作方法や注意事項は、画面右上の「使い方」にまとめています。流派・一般技能、CSVの登録、途中保存・再開、JSON出力の手順もそちらをご覧ください。

ゆとシートでコピーした駒を「出力」→「ココフォリア用の駒」に貼ると、通常移動力とカード所持数を反映してコピーできます。

## データ管理

CSVの登録・保存・ひな形と辞書編集は「設定」→「データ管理」にまとめています。価格辞書、加工、流派・名誉点、一般技能をここから管理できます。普段の画面には、登録したデータを使う操作だけが表示されます。CSVなしの手入力も可能です。

流派・一般技能は「登録データを見る」から、キャラクターを読み込まずに内容を確認できます。未入門の秘伝や一般技能の判定も閲覧できますが、キャラクターへの追加・習得は通常の編集画面で行います。4種類のひな形と「CSV作成ガイドDL」は、下部の「CSVひな形・作成ガイド」にまとめています。CSVの書き方はダウンロードしたガイドをご覧ください。

## 流派・専用化

「設定」→「データ管理」→「流派・名誉点」でCSVを登録します。メイン画面の「流派」で選んで「入門する」を押すと、その下に秘伝・秘伝魔法が並びます。行いたい習得を続けて選べます。条件と必要名誉点は同じ欄で確認できます。今回の入門を取り消すと、その流派で今回選んだ秘伝・秘伝魔法も取り消します。元からの取得は保持します。

選択欄はCSVの書籍（source）・区分（任意列browseGroup）で区切ります。書籍・区分・流派の並びはCSVの初出順です。

専用化は名前の右の「専用」列で行います。武器・防具はチェック、装飾品は空欄／HP／MPを選びます。新たに専用化した分の名誉点だけを登録し、外すと今回分を取り消します。武器欄の「その他」道具では、CSVにある専用化の種類を選びます。選んだ種類や費用はヒント・「名誉点の記録」で確認できます。CSVに費用がないものを推測して計算しません。

読み込んだ既存の取得・専用化は再消費しません。装飾品の既存HP／MP設定を変える操作も、取得費を重ねません。過去の費用は装備を外しても返還しません。支払済み記録への対応付け、理由付きの無料扱い、未記入・0点記録の補完は「名誉点の記録」で選べます。価格・加工CSVによる購入分の追加名誉点もここで確認できます。ランクによる無料扱いは自動判定しません。

変更確認で取得と費用をまとめて選び、ゆとシート標準の記録・専用化フラグへ反映します。残高そのものは書き換えず、ゆとシートで再計算されます。道具の専用化に伴う魔力などの補正や、過去費用の自動払い戻しは行いません。CSVの詳細は「CSV作成ガイド」へ。書籍由来のデータは同梱しません。

## 一般技能

「設定」→「データ管理」→「一般技能」で専用CSVを登録すると、メイン画面の「一般技能」で技能と行える判定を選べます。CSVにない技能・判定は手入力できます。レベルを設定し、パレットへ出す判定を選んでJSONへ反映してください。ゆとシートへ取り込んだ後、通常どおりココフォリア用の駒を出力すると、選択した個別判定名を含められます。

技能の選択欄は、CSVにある書籍名の太字見出しで区切ります。書籍名が空欄のCSVも使えます。

使用できるレベルの条件は確認しますが、技能の特典・場面別の追加補正は自動計算しません。必要なら「追加修正」を入力してください。手入力のみのパレット設定では、ゆとシート側で自動パレットを併用する設定も必要です。既存の手書き文や他の追加パレットは保持します。

書籍由来の一般技能CSVは付属しません。データ管理から空のひな形と作成方法を確認できます。一般技能CSVは個人用設定バックアップに含み、共有用には含みません。

読み込んだ既存技能は、編集または「この判定を使う」を選ぶまで元の出力設定を保持します。ゆとシートの再保存で独自の管理情報が残らなかった場合も、生成文とCSVから判定を復元します。ただし、CSVにない手入力判定を出力OFFにしていた場合、その判定名は再設定が必要になることがあります。元の編集を完全に残すには本ツールの途中保存も利用してください。

## セッション後の更新

画面上部の「セッション前」「セッション後」で作業を切り替えます。切り替えても、それぞれの入力は残ります。各画面の対象名・参照URLを確認して作業してください。初回だけコピー用ボタンをブックマークバーへ登録し、ココフォリアの駒の編集画面で押してから、本ツールへ貼り付けてください。通常の右クリックコピーでは残数を取得できません。

所持数への反映、入手品・手動の減少、任意のセッション履歴を確認できます。日付は手入力のほか、カレンダーから複数日を同じ欄に追加できます。自動入力の既定書式は `YY/MM/DD` です。部屋・チャット・オンラインシートは自動更新しません。コピー用ボタンはPCのChromeで確認済み、スマホでの登録・実行は未検証です。

買い物を続けるなら「買い物へ進む（出力はあとで）」で更新後の所持品・残金を引き継ぎます。セッション後の更新と買い物をまとめて確認し、最後にJSONを1回出力します。買い物をしないならセッション後で「JSONを出力」を選びます。セッション後の入力欄自体は途中保存の対象外ですが、買い物へ引き継いだ後は途中保存できます。

閲覧URLから読み込んだ場合は、最終JSONの出力前に保存済みのシートを再確認します。別の変更があれば、変わった欄を案内して出力を止めます。ゆとシートで編集中の未保存内容は確認できません。

今回の購入分は「日付 買い物」にまとめます。収支履歴の末尾に同じ回の枠があれば追記し、それ以外は末尾に追加します。セッション前で直接読み込んだ場合は出力欄で対象の回を選べます。回を指定しない場合は「今回の購入日」だけを選ぶか、空欄で従来の品目別出力にできます。

コピー完了を3秒以内に確認できない場合は、表示された「全文を選択」から手動でコピーしてください。コピー中のまま止まる旧版のボタンは、登録し直す必要があります。貼り付け先でも名前と現在値を確認してください。

同名（半角・全角だけの違いを含む）のステータスがある駒は、安全に対応付けできないため取り込めません。駒側で別名にしてコピーし直してください。コピー補助v0.1.3では、この案内も統一しています。

ゆとシートへ保存すると独自の再適用検出情報が残らない場合があります。同じ日付・タイトル・GMの履歴には警告を出しますが、二重反映を完全に防ぐものではありません。

## 価格辞書と加工データ

ルールブック・サプリメントの商品一覧や価格表は付属していません。CSVを登録すると、辞書からアイテムを探して比較・追加したり、登録された加工データを利用したりできます。CSVなしの手入力でも利用できます。

CSVを自作する場合は、「設定」→「データ管理」→「CSVひな形・作成ガイド」から、空のひな形と共通の作成ガイドをダウンロードしてください。別途サンプルCSVを取得する必要はありません。

加工CSVは置換前に確認でき、「直前の加工CSVへ戻す」で1つ前の状態へ戻せます。CSVを表計算アプリで開く場合は、数式に見える文字列を実行しないよう文字列として取り込んでください。

カース名は、名称照合表入りの加工CSVを「設定」→「データ管理」→「加工」の「強化CSV」から読み込むと一緒に登録されます。商品ごとの略称は価格CSVの `aliases` 列で指定できます。

加工CSVの任意列 `nameRules` で、既存装備の加工名を照合し、新規加工では指定した表記を装備名とJSONへ反映できます。既存の名前から分かった加工は再計上・再加算しません。カース名の選択は名前だけに使い、カース固有の効果は数値に反映しません。

## 保存について

- ゆとシートへは自動保存しません。出力したJSONをゆとシートへ取り込み、内容を確認して保存してください。
- 辞書・設定・途中保存は、利用中のブラウザに保存されます。端末やブラウザが異なる場合、自動では同期されません。
- 「途中保存」は編集中の作業用、「設定バックアップ」は辞書・設定などの移行用です。用途に合わせて使い分けてください。
