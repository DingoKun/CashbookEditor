# SW2.5 収支・持ち物エディタ

ゆとシートのソード・ワールド2.5用キャラクターデータを読み込み、買い物の収支や装備・所持品を整理する、ブラウザで使えるツールです。編集した内容を確認して、ゆとシートへ取り込むJSONを出力できます。

**[ツールを開く](https://dingokun.github.io/CashbookEditor/)**

## 使い方

公開ページを開き、キャラクターシートの閲覧URLからデータを読み込んでください。アイテムの追加・加工・買い足しを行い、変更内容を確認してJSONを出力します。

詳しい操作方法や注意事項は、画面右上の「使い方」にまとめています。CSVの登録、途中保存・再開、JSON出力の手順もそちらをご覧ください。

ゆとシートでコピーした駒を「出力」→「ココフォリア用の駒」に貼ると、通常移動力とカード所持数を反映してコピーできます。

## セッション後の更新

画面上部の「セッション前」「セッション後」で作業を切り替えます。切り替えても、それぞれの入力は残ります。各画面の対象名・参照URLを確認して作業してください。初回だけコピー用ボタンをブックマークバーへ登録し、ココフォリアの駒の編集画面で押してから、本ツールへ貼り付けてください。通常の右クリックコピーでは残数を取得できません。

所持数への反映、入手品・手動の減少、任意のセッション履歴を確認できます。日付は手入力のほか、カレンダーから複数日を同じ欄に追加できます。自動入力の既定書式は `YY/MM/DD` です。部屋・チャット・オンラインシートは自動更新しません。コピー用ボタンはPCのChromeで確認済み、スマホでの登録・実行は未検証です。

買い物を続けるなら「買い物へ進む（出力はあとで）」で更新後の所持品・残金を引き継ぎます。セッション後の更新と買い物をまとめて確認し、最後にJSONを1回出力します。買い物をしないならセッション後で「JSONを出力」を選びます。セッション後の入力欄自体は途中保存の対象外ですが、買い物へ引き継いだ後は途中保存できます。

閲覧URLから読み込んだ場合は、最終JSONの出力前に保存済みのシートを再確認します。別の変更があれば、変わった欄を案内して出力を止めます。ゆとシートで編集中の未保存内容は確認できません。

今回の購入分は「日付 買い物」にまとめます。収支履歴の末尾に同じ回の枠があれば追記し、それ以外は末尾に追加します。セッション前で直接読み込んだ場合は出力欄で対象の回を選べます。回を指定しない場合は「今回の購入日」だけを選ぶか、空欄で従来の品目別出力にできます。

コピー完了を3秒以内に確認できない場合は、表示された「全文を選択」から手動でコピーしてください。コピー中のまま止まる旧版のボタンは、登録し直す必要があります。貼り付け先でも名前と現在値を確認してください。

同名（半角・全角だけの違いを含む）のステータスがある駒は、安全に対応付けできないため取り込めません。駒側で別名にしてコピーし直してください。コピー補助v0.1.3では、この案内も統一しています。

ゆとシートへ保存すると独自の再適用検出情報が残らない場合があります。同じ日付・タイトル・GMの履歴には警告を出しますが、二重反映を完全に防ぐものではありません。

## 価格辞書と加工データ

ルールブック・サプリメントの商品一覧や価格表は付属していません。CSVを登録すると、辞書からアイテムを探して比較・追加したり、登録された加工データを利用したりできます。CSVなしの手入力でも利用できます。

CSVを自作する場合は、画面内の「辞書・加工データ管理」→「CSVひな形・作成ガイド」から、空のひな形と共通の作成ガイドをダウンロードしてください。別途サンプルCSVを取得する必要はありません。

加工CSVは置換前に確認でき、「直前の加工CSVへ戻す」で1つ前の状態へ戻せます。CSVを表計算アプリで開く場合は、数式に見える文字列を実行しないよう文字列として取り込んでください。

カース名は、名称照合表入りの加工CSVを「武器・防具の加工データ管理」→「強化CSV」から読み込むと一緒に登録されます。商品ごとの略称は価格CSVの `aliases` 列で指定できます。

加工CSVの任意列 `nameRules` で、既存装備の加工名を照合し、新規加工では指定した表記を装備名とJSONへ反映できます。既存の名前から分かった加工は再計上・再加算しません。カース名の選択は名前だけに使い、カース固有の効果は数値に反映しません。

## 保存について

- ゆとシートへは自動保存しません。出力したJSONをゆとシートへ取り込み、内容を確認して保存してください。
- 辞書・設定・途中保存は、利用中のブラウザに保存されます。端末やブラウザが異なる場合、自動では同期されません。
- 「途中保存」は編集中の作業用、「設定バックアップ」は辞書・設定などの移行用です。用途に合わせて使い分けてください。
